Архітектура проєкту:



/cosmos-blackholes-site

├─ index.html                ← головна сторінка (Варіант 2)

├─ /pages/                   ← 5 екземплярів сторінки (п.5 завдання)

│   ├─ v1.html

│   ├─ v2.html

│   ├─ v3.html

│   ├─ v4.html

│   └─ v5.html

├─ /styles/                  ← стилі, розділені за призначенням

│   ├─ base.css              ← базові токени/скидання/типографія/утиліти

│   ├─ layout.css            ← сітка Варіанту 2 + семантичні зони 1–6, X, Y

│   ├─ components.css        ← дрібні повторно-використовні елементи

│   └─ theme.css             ← легка кольорова тема блоків

├─ /scripts/

│   └─ main.js               ← заглушка JS + гачки через data-js (готово до розширення)

├─ /assets/

│   ├─ /img/                 ← сюди класти зображення

│   ├─ /fonts/               ← локальні шрифти

│   └─ /icons/               ← SVG/ICO

└─ README.md                 ← інструкції/архітектура проєкту
